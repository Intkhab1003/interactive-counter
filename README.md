## 🚀 Key Features

- **Real-time State Management:** Zero-reload metric tracking (Increase, Decrease, Reset).
- **Session Analytics Sidebar:** Dynamic calculation of Session Highest, Lowest, and total operation counts.
- **Activity Log:** Auto-updating history feed displaying the 10 most recent actions with precise timestamps.
- **Premium Glassmorphism UI:** Midnight navy aesthetic featuring frosted glass panels, glowing accent gradients, and animated floating background orbs.
- **Hardware-Accelerated Animations:** Smooth 3D hover tilt effects, tactile button press feedback, and value transition scaling.
- **Accessibility & UX:** 
  - Full Light/Dark theme toggling.
  - Native Web Audio API sound feedback (Muted by default).
  - Strict adherence to `prefers-reduced-motion` media queries.
  - Fully responsive CSS Grid / Flexbox layout for mobile and desktop.

## ⌨️ Keyboard Shortcuts

Designed for power users, the dashboard can be operated fully via keyboard (automatically disabled when typing in inputs):
- `Arrow Up` - Increase Value
- `Arrow Down` - Decrease Value
- `R` - Reset to Zero

## 🛠️ Tech Stack & Architecture

- **Structure:** Semantic `HTML5`
- **Styling:** `CSS3` (Custom Properties, Backdrop-filter, Grid/Flex, 3D Transforms, Media Queries)
- **Logic:** Vanilla `JavaScript (ES6+)` (DOM Manipulation, Web Audio API, Event Listeners)
- **Icons:** Phosphor Icons
